# 🌿 CropGuard AI – AI Farmer Copilot

> **International Hackathon Project | SDG 2 – Zero Hunger**

An AI-powered multilingual farmer assistant that detects crop diseases from a leaf image, estimates disease severity, recommends treatment, and provides actionable insights within seconds.

---

## 🚀 Why CropGuard AI?

Every year, farmers lose crops because diseases are identified too late. CropGuard AI enables early detection using a smartphone, helping farmers make faster and smarter decisions.

## ✨ Key Features

- 📸 AI Leaf Disease Detection
- 🎯 Confidence Score
- ⚠️ Disease Severity Analysis
- 💊 Treatment Recommendation
- 🌍 Multilingual Support (Future)
- 📱 Mobile-Friendly Interface
